## Overview

We study how bimanual imitation policies behave when the visual task remains nearly identical, but the hidden pulling resistance changes.

This preview focuses on three representative train–test settings:

<table>
  <tr>
    <th>Setting</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><strong>9 N → 9 N</strong></td>
    <td>In-regime high-force execution.</td>
  </tr>
  <tr>
    <td><strong>9 N → 3 N</strong></td>
    <td>Downward transfer to an easier resistance regime.</td>
  </tr>
  <tr>
    <td><strong>3 N → 9 N</strong></td>
    <td>Upward transfer failure under harder resistance.</td>
  </tr>
</table>

## Key Takeaway

The videos provide an intuitive view of the main observation:

> High-force-trained policies can transfer to easier regimes, while low-force-trained policies often fail when tested under higher hidden resistance.
